# Trading Lab · Practicá trading sin arriesgar dinero

Laboratorio educativo de trading con dinero ficticio. Incluye:

- **Simulador** de mercado con gráfico de velas, órdenes, comisiones y apalancamiento.
- **Predicción**: adiviná la próxima vela y medí tu acierto.
- **Opciones**: calls y puts con su perfil de pago.
- **Probabilidad**: simulación Monte Carlo de estrategias.
- **Retos**, **estadísticas** de desempeño y lecciones en **Aprende**.

**Probalo:** https://trading-lab-raiz.vercel.app

HTML, CSS y JavaScript puro, sin dependencias. Todo corre en el navegador y el progreso se guarda en localStorage.

> Herramienta educativa. No es asesoramiento financiero ni una invitación a invertir.
